# Extensions
Frequently Asked Questions about Extensions.

## Where can I find repositories/extensions for Nekori?
Nekori does not provide or distribute any repositories or plugins, and is not affiliated with third-party repositories or plugins.

::: danger Caution
Third-party plugins run code within the app and may contain malware.
Only install plugins from sources you trust.
:::

## What are some recommended extensions and sources?
Nekori is bring-your-own-content and does not offer or recommend any plugins or sources.

::: info Disclaimer
**Nekori** isn't responsible for slow, down, missing chapters, or subpar chapter quality of sources as it doesn't host the content.
:::

## How do extensions work in Nekori?
Nekori extensions are JavaScript plugins that run on Hermes, the JavaScript engine used by its React Native runtime.
They are managed within Nekori, not installed as separate Android apps.
Mihon-style APK extensions are not supported.
JavaScript plugins do not require Android’s **Install unknown apps** permission, but allowing it for Nekori is recommended so you can install app updates downloaded through the app.

## How do I uninstall an extension?
Manage installed novel plugins in **Nekori**; they are not separate Android apps.

::: tip Uninstalling an extension
In **Nekori**, uninstall an extension via <nav to="extensions">, then tap **Uninstall** on the chosen extension.
:::
